# PopX App

Earlier iteration of the [PopX](https://github.com/ashish28-art/popx) multi-screen onboarding UI, built with React, Vite, and Tailwind CSS.

## Overview

A front-end implementation of the PopX mobile app design: welcome screen, sign-in, account creation, and account settings, rendered as a single-page flow with screen switching in React state. There is no backend — forms validate client-side only.

The more recent, refined version of this project lives at [ashish28-art/popx](https://github.com/ashish28-art/popx) (includes a live demo).

## Screens

- **Welcome** — landing page with Create Account and Login options
- **Sign In** — email and password form
- **Create Account** — registration form with agency radio button
- **Account Settings** — user profile display

## Tech Stack

- **Frontend:** React 19, JSX
- **Styling:** Tailwind CSS 3, PostCSS
- **Build tool:** Vite

## Getting Started

Prerequisites: Node.js 18+ and npm.

```bash
npm install
npm run dev
```
